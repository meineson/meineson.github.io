    • 国产AI模型神仙打架，AI Agent流浪记

    年初那波小龙虾和爱马仕把算力给干缺货了，不知道大家有没有感觉，反正我是完整经历了一轮被各大厂商花式服务的”洗礼”——被封号、被砍额度、被取消订阅，注册一个死一个，账户游民一样到处流浪，最后居然是一个叫Opencode的小透明收留了我。

    价格：国产模型把桌子掀了

    先看价格。按每1M tokens算：

    模型 输入 输出
    Deepseek V4 Flash ¥1 ¥2
    小米 Mimo v2.5 Flash ¥1 ¥2
    Deepseek V4 Pro ¥3 ¥6
    小米 Mimo v2.5 Pro ¥3 ¥6
    GPT-5.4 ¥18 ¥109
    GPT-5.4 mini ¥5.4 ¥33
    Claude Sonnet 4.6 ¥22 ¥109
    Claude Haiku 4.5 ¥7.3 ¥36

    Deepseek和Mimo两家像是约好了一样，Pro都降到了¥3入/¥6出，Flash都降到了¥1入/¥2出。GPT-5.4输出要¥109，国产Flash只要¥2，差了五十几倍，不是卷不卷的问题了，是直接掀桌子。

    流浪记

    我是春节过后那段时间，各种服务开始对国内用户收紧的。

    先是Google新注册的账号被封，各种要求国外手机号接收验证码短信。后来换了个老gmail账号注册Play商店订阅，勉强能稳定用，但额度一直砍到几乎不可用的程度——$19.9的Plus订阅，动不动告诉你要一周后恢复额度，真TMD。

    接着Claude Code也被封。Anthropic这波扫射范围之广大家都知道，都学上了实人认证，信用卡金融级别的安保了…

    然后是OpenAI Codex，弹短信验证码（不认+86手机号），用google账号关联登录了，google账号被封连带Codex也登不上了。

    GitHub Copilot紧随其后，原本的按请求次数定价的订阅直接砍掉，改成了按token计费。本来想用它当主力的，因为就它能稳定访问Claude模型，结果后面新的token套餐直接不给”低端”用户开放Claude了，只有GPT系列，那我还不如直接用OpenAI。

    国内的也没好到哪去。阿里云Coding Plan取消，Qwen免费额度取消，Kimi好的不学还跟着国外厂商学起了API不在指定软件调用要封号那一套。

    一直在Codex、Claude Code、Gemini CLI、Qwen CLI、Google Antigravity、Copilot CLI之间反复横跳。这个被封了用那个，那个欠费了掏钱，注册一个死一个。

    最后一直还能用的，居然只剩下了Opencode——它没国内国外大厂的巨额经费去造势，只能用硬实力出圈，这其实也是我第一个使用的编程Agent。

    Opencode：流浪的终点

    Opencode现在也不是只有CLI，基本都和Codex、Antigravity一样出了桌面和CLI两套，适应不同场合需求（我发现多模态模型CLI下很难成功，桌面的就好用些，比如Kimi和Mimo）。

    而它的GO订阅几乎是专为国人准备的，首月$5试用（后续$10），几乎是清一色国产模型。这几天用Deepseek V4 Flash写实际的软件工程代码，从需求分析到代码实现到调试修复，高强度干了一整天，用量进度条几乎没动过。

    这特么比直接去Kimi、GLM官方订阅渠道性价比都高，他们居然还搞抢购！！

    还有个隐藏优势——GO订阅不只是给Opencode自己用的，可以直接当API接口用。你接OpenClaw也好，自己写脚本调HTTP也罢，随便。不限制你是在编程Agent里用还是在别的地方用。

    这点经历过被封的人才懂有多重要。国外御三家（OpenAI、Anthropic、Google）加上Copilot，基本都禁止在官方软件之外调用API，检测到就直接封号。国内Kimi之流好的不学，也跟风搞这一套。

    Opencode反其道而行之，你付了费想怎么用就怎么用，这才是订阅该有的样子。

    MyOCUsage：给Opencode配了个仪表盘

    用GO订阅之后，一直想看用量又懒得开浏览器。懒人驱动生产力，写了个macOS菜单栏小工具，开源在GitHub上了：https://github.com/meineson/MyOCUsage

    菜单栏直接显示用量百分比，动态瓶子图标从满到空、颜色从蓝到红变化，三个时段（5小时滚动、本周、本月）的进度条和倒计时都有，下拉菜单还有饼图按模型拆分当月用量。单Python文件，不需要装Xcode编译，pip3 install -r requirements.txt 就能跑。

    配置也简单：Opencode网页F12 Network里抄几个字段填到config.json就行。注意Cookie会过期，过期了菜单栏会显示🔒，重新复制一次就恢复。

    现在我的开发环境就是Opencode CLI写后端，Opencode桌面写前端，菜单栏挂着MyOCUsage看用量。一天下来进度条几乎不动，心里踏实得很。

    总结

    国外厂商筑墙、涨价、砍额度，国产厂商敞开大门、降价、搞促销。¥2出/1M token vs ¥109出/1M token，五十几倍的价差，能力是有差距，但你能得到的价值有没有多五十倍？反正我感觉没有。别跟自己钱包过不去。

    首月$5就能用上Deepseek V4 Flash和Mimo Pro这个级别的模型，找个顺手的编程Agent或OpenClaw接上，一年前的开发者想都不敢想。该上车了。
